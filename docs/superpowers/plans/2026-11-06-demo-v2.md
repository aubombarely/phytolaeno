# Phytolaeno Demo v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the half-synthetic demo with an all-real, three-species demo (41 annotations) whose pages follow Species → Assemblies → Annotations, with descriptions, source links, insight tags, and filterable plots including a GAQET radar ranked by the Global Annotation Score.

**Architecture:** A one-off extractor turns the benchmark spreadsheet into committed TSVs under `demo/data/`. `scripts/demo.py` loads those TSVs into SQLite. Pure functions in `app/metrics.py` (GAQET axes, GAS, tags) and `app/links.py` (external links) are shared by the routers. Plot figures are built by one module that both `/plots` and the species page call. Filters and weights are query parameters handled server-side, so there is no duplicate JS logic.

**Tech Stack:** Python 3.10+, FastAPI 0.115.6, SQLAlchemy 2.0.57, Jinja2, plotly.py 7.1.0 / Plotly.js 4.1.1, pandas + openpyxl (extractor only), pytest + httpx.

**Spec:** `docs/superpowers/specs/2026-11-06-demo-v2-design.md`

## Global Constraints

- Stay on SQLAlchemy 2.0.x; keep all pins in `requirements.txt`; Plotly.js stays `https://cdn.plot.ly/plotly-4.1.1.min.js`.
- Tests run on SQLite with no PostgreSQL: `python -m pytest -q tests`.
- `scripts/import_excel.py` must keep working unchanged. Every new column is nullable, and templates hide empty fields.
- The demo is entirely real: no synthetic species, generator code or "synthetic data" banner.
- Three species: *Arabidopsis thaliana*, *Oryza sativa*, *Cucumis sativus*. There are 5 assemblies (TAIR10, TAIR12, Osativa_204, ChineseLong_genome_v3, GCF_000004075.3 9930 V3) and 41 annotations (16 + 12 + 13).
- `Athaliana_447_Araport11` and `TAIR10_chr_all` are one assembly, displayed as "TAIR10".
- Ranking everywhere is by GAS, computed on load. The spreadsheet's `Annotation_Rank` is ignored.
- GAQET axes and GAS must match the GAQET2 `revision` branch `GAQET/gaqet_plot.py`.
- "No UTRs" tag: max(UTR5', UTR3') / transcript models < 0.01. Threshold constant `NO_UTR_FRACTION = 0.01`.
- Micro-exon tag is hidden while `micro_exon_pct` is None. Never use `Shortest Intron Length` for a tag.
- References (grey, "Reference"):
  - *A. thaliana*: Araport11, TAIR10, TAIR12, RefSeq GCF_000001735.4
  - *O. sativa*: MSU r7 `osa1_r7`, RefSeq GCF_034140825.1
  - *C. sativus*: ChineseLong v3 official, RefSeq GCF_000004075.3
  - Everything else is a tool run, including the user's EGAPx run.
- No download control unless a URL exists.
- Descriptions and tag explanations: Claude drafts them and the **user reviews them before they are committed**. GeneDAIS proposal text is restricted and must be paraphrased, never copied.
- Blueprint: palette blue `#4C9BE8` (tool runs), red `#E8604C` (warning), grey `#888888` (reference/neutral), amber `#F5A623` (UTR warning). Version bump to **v0.3.0** with CHANGELOG, README badge and CITATION.

## Review Focus

1. **An annotation with a missing analysis** (e.g. no OMArk, DeTEnGA or PSAURON value). GAS should skip that axis as GAQET does, the radar should draw it at 0, and nothing should crash. Tested in Task 3 (`test_gas_skips_missing_axis`).
2. **Transcript models of 0 or None.** No division error: the AGAT axis is None, and the UTR and isoform tags are absent. Tested in Task 3 (`test_tags_handle_zero_transcripts`).
3. **Malformed plot query parameters** (unknown species or assembly id, non-integer ids, `weights=busco:abc`, all weights 0). The page should return 200, fall back to defaults and show a short notice, never 500. Tested in Task 7 (`test_plots_bad_params_fall_back`).
4. **A production assembly with no QUAST fields or description** (import_excel data). Pages render with those rows hidden. Tested in Task 5 (`test_species_page_without_new_fields`).
5. **A reference annotation with zero UTRs** (none exist in this data). References are still never tagged with warnings. Tested in Task 3 (`test_reference_never_warned`).

### Task 3: Metrics: GAQET axes, GAS, tags

**Files:**
- Create: `app/metrics.py`
- Test: `tests/test_metrics.py`

**Interfaces:**
- Produces:
  - `AXES: list[tuple[str, str]]`: (axis_key, role) pairs in GAQET order:
    `("swissprot","homology"), ("trembl","homology"), ("omark_species","omark"), ("busco_viridiplantae","busco"), ("busco_embryophyta","busco"), ("detenga_pcpm0","detenga"), ("psauron","psauron"), ("agat_no_startstop","agat")`
  - `AXIS_LABELS: dict[str, str]`: display labels as in GAQET, e.g. `"Proteins fitting their Taxonomic rank (OMARK)"`.
  - `gaqet_axes(ann) -> dict[str, float | None]`. `ann` is any object with GeneModelAnnotation attributes.
  - `role_shares(weights: dict[str, float] | None) -> dict[str, float]`: role → percentage. Unmentioned roles split the remainder equally. Raises `ValueError` if the sum exceeds 100 or a role is unknown.
  - `gas_score(axes: dict[str, float | None], weights: dict[str, float] | None = None) -> float | None`. Each role's share is split equally among that role's **available** axes. A role whose axes are all None is dropped and the shares are renormalized over the remaining roles, matching GAQET's "analysis missing" behaviour.
  - `Tag` dataclass with fields `key, label, kind, explanation_key`. `kind` is `"warning"` or `"info"`.
  - `annotation_tags(ann) -> list[Tag]`
  - Constants: `NO_UTR_FRACTION = 0.01`, `MICRO_EXON_WARN_PCT = 1.0`.
- Axis formulas (verbatim from GAQET2 revision):
  - `omark_species`: the number captured by `r":\s*([\d.]+)%"` in `omark_species_composition`
  - `detenga_pcpm0`: the number captured by `r"PcpM0:\s*([\d.]+)"` in `detenga_fp_pct_raw`
  - `agat_no_startstop`: `100 - 100 * (start_missing + stop_missing + start_stop_missing) / transcript_models`
  - `busco_*`: the complete % values
  - `swissprot`, `trembl`: the percentages
  - `psauron`: `psauron_score`

  - `test_gas_role_weights`: with `{"busco": 40}`, the two BUSCO axes get 20% each and the other 6 axes split 60% equally.

- Produces:
  - `parse_plot_params(species_id: str | None, assembly_id: str | None, annotation_ids: str | None, metric: str | None, weights: str | None) -> PlotParams`. `PlotParams` is a dataclass with fields `species_id: int | None`, `assembly_id: int | None`, `annotation_ids: list[int]`, `metric: str`, `weights: dict[str, float] | None` and `notices: list[str]`. It never raises; invalid input is replaced by defaults and a notice is added.
  - `METRICS: dict[str, tuple[str, Callable]]`, mapping key → (label, getter). Keys: `busco_viridi`, `busco_embryo`, `gene_models`, `psauron`, `utr_pct`, `isoforms`, `mean_intron`, `single_exon`, `gas`. Default metric: `gas`.
  - `build_figures(db, params: PlotParams) -> dict[str, str]`, returning figure JSON for the keys `within`, `across` and `radar`, plus `repeats` when the assembly level applies.

    - **radar:** one `Scatterpolar` per selected annotation (default: all of the selected assembly), with axes in `AXES` order, None drawn as 0, and the legend sorted by GAS under the given weights.
  - Query string: `?species_id=&assembly_id=&annotation_ids=1,2,3&metric=gas&weights=busco:40,omark:10`. The sliders are an HTML form with one range input per role and auto-submit on change.
